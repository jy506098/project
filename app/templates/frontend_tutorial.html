HTML + CSS + JavaScript · 零基础到部署

1. HTML 骨架

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的网页</title>
</head>
<body>
    <h1>Hello, 前端!</h1>
</body>
</html>

2. CSS 美化

h1 {
    color: #3498db;
    text-align: center;
    font-family: 'Helvetica', sans-serif;
    background: linear-gradient(135deg, #667eea, #764ba2);
    -webkit-background-clip: text;
    color: transparent;
}

3. JavaScript 交互

document.querySelector('h1').addEventListener('click', () => {
    alert('你点我了!');
});

// ES6+ 语法糖
const fetchData = async (url) => {
    const res = await fetch(url);
    return res.json();
};

4. 响应式布局

.container {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
    gap: 1rem;
    padding: 1rem;
}

@media (max-width: 768px) {
    .container { grid-template-columns: 1fr; }
}

5. 部署上线

  • 静态站点：Vercel / Netlify / GitHub Pages
  • 构建工具：Vite / Webpack
  • 现代框架：React / Vue / Svelte
  • CSS 框架：Tailwind / UnoCSS
